# Create a Ghost Dashboard Skin

## Steps

1. **Duplicate `base/`** into `community/<skin-name>/`.
   - Simple, lowercase, hyphenated names: `duck`, `space-drift`, `cookies-n-cream`.
   - Check the name is not already used in `community/`.

2. **File structure:**
   ```
   community/<skin-name>/
   ├── index.html       # Entry point, loads the scripts in order
   ├── script.js        # Skin logic
   ├── style.css        # Skin styles
   ├── README.md        # Skin name (shown to the user in the selection list), description, inspiration, features
   └── screenshot.png   # Screenshot of the skin in action
   ```

3. **`index.html` script order is critical.** Skins live two levels deep, so the shared assets are at `../../assets/` (this is what `base/`, `community/simple` and `community/scale` use):
   ```html
   <div id="container"> ... </div>

   <script src="../../assets/defaultSettings.js" type="text/javascript"></script>
   <script src="../../assets/client.js" type="text/javascript"></script>
   <script src="./script.js" type="text/javascript"></script>
   ```
   `client.js` looks up `#container` when it is evaluated, so the `#container` element must exist in the HTML **before** the `client.js` tag (it cannot be created later from `script.js`).

4. **`script.js` minimum skeleton:**
   ```js
   const callback = () => {
     const { cMain, cSec } = COLORS
     const { rpmM } = DASH_OPTIONS
     const maxRpm = rpmM * 1000
     const container = document.getElementById('container')
     const kmTotal = document.getElementById('kmTotal')
     const kmTrip = document.getElementById('kmTrip')

     // Theme colors
     setRootCSS('--main-color', cMain)
     setRootCSS('--second-color', cSec)

     // Restore saved odometer values
     loadOdo(kmTotal, kmTrip, 0)

     const bindRealtimeData = () => {
       // ... read basicData / canData here
       updateOdo(kmTotal, kmTrip, useCanChannel('sVss') ? canData.odoNow : basicData.odoNow)
       requestAnimationFrame(bindRealtimeData)
     }

     // Open the connection once the intro animation has finished
     // (base/ and simple use 6500 ms, scale uses 5000 ms)
     setTimeout(() => openConnection(bindRealtimeData), 6500)

     // Last step: trigger the intro animation
     container.classList.add('anim-in')
   }

   window.onload = () => callback()
   ```

5. **Canvas:** 1280×480 px. Responsive layout is not required; scalable designs are recommended (the hardware renders at 1x, 1.5x or 2x).

6. **Test in the devkit:** `npm run serve`, open `http://localhost:3210`, click **Load dev skin** and type the folder name (just `<skin-name>`, the devkit prepends `./community/`). The choice is remembered in localStorage; **Reset settings** clears it.

7. **Submit:** open a PR against `main` of the upstream SDK repo; skins are tested on real hardware before release.

## Bundled skins (Vite, etc.)

A skin can be built from sources (see `community/honda-retro/`), as long as the output behaves like a hand-written skin:
- Output a single **classic script** (`format: 'iife'`), named `script.js`, into the skin folder. No ES modules: `index.html` loads it with a plain `<script>` tag after `client.js`.
- The SDK API is plain globals (`COLORS`, `DASH_OPTIONS`, `basicData`, `canData`, `setText`, ...). Don't import them; declare them for the linter (`/* global ... */`).
- `index.html` stays hand-maintained with the script order above; keep `node_modules/` out of git.

## Notes
- `COLORS` is `DASH_OPTIONS.theme.colors`. User-themeable colors: `cMain`, `cSec`, `cRed`, `cBg`, `cRpm`.
- `DASH_OPTIONS` = `defaultSettings.js` merged with what the user saved. Many values are **strings** (`redline: "5500"`, `clt: "110"`), so coerce with `+` before comparing or doing math.
- Every `client.js` function is global once the script is loaded. Don't edit `assets/` (`client.js`, `defaultSettings.js` are generated by the SDK).
- The RPM gauge must support the 5 user-selectable maxima `rpmM` = 6, 7, 8, 9, 10 (×1000). See `implement-gauges`.
- `base/script.js` hardcodes `maxRPM = 8000`; replace it with `DASH_OPTIONS.rpmM * 1000` in your skin.
